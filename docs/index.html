00 — 世界观

世界法则破碎之后

原本普罗米修也如其他世界一样正常运转。神罚落下后，分崩离析的法则碎片无法再像往常一样维持整个世界的规律，破碎的碎片也阻挡不住外来法则——苍穹之外的各种法则力量涌入普罗米修。

在各类法则力量的影响下，普罗米修不仅没有毁灭，反而以一种诡异且稳定的状态运转。数万年来，人们对法则引起的怪异现象习以为常，并开始借用法则之力，去做先前世界根本做不到的事。

随着探索更进一步，世人发现破碎的法则换来更多未知的同时，不少法则碎片早已淹没于时间长河中，不知去向。

世人的魔法与科技如何发展，都无法离开这片苍穹之下的世界。
